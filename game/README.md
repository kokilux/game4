# KA — 夜の蚊取り

> 蚊 × 睡眠。10晩（和室 → 洋室 → 夏の夜 → 子ども部屋 → ホテル → 山小屋 → 夜行列車 → 海辺の家 → キャンプ → 蚊帳の間）、1晩40〜52秒。
> **着地の直前に「止まる」一瞬**が最大の狙い目。**飛んでいる蚊も、小さい判定で叩ける。**

暗い寝室。耳元で羽音がする。蚊は壁・布団・そしてあなたの顔に着地する。
着地の0.3秒前、蚊はホバリングして震える（＝予備動作）。そこが唯一の狙い目。
飛んでいる最中に叩ければ大きな加点（+130）、遅れれば刺される。空振りすると近くの蚊は驚いて逃げる。

```
npm run dev          # http://localhost:5173/game/  (320x180 をウィンドウいっぱいに拡大)
```

- **操作**：マウス／指で手を動かす、タップ／Space で平手。`↑↓` メニュー、`Space/Enter` 決定、`Esc`/`P` ポーズ、`M` 無音、`C` 原則ラベルの表示切替、`R` タイトルへ
- **画面**：タイトル（メニュー）→ プレイ → クリア画面 → 次の夜 … 3晩でリザルト。UIは全部キャンバスの中に描く
- **ルール**：各晩の蚊を全部捕まえれば夜明け前でもクリア、次の部屋へ（クリアで ♥ が1つ回復）。刺されると睡眠（♥3）が減り、0でその夜は終わり
- **得点**：捕獲 +100 / **空中で捕獲 +130** / 着地から素早く叩く +50 / ステージクリア +500＋残り時間×10、夜明け +100
- **コンボ**：ミスせず連続で仕留めると3匹ごとにボーナス（+120＋コンボ×30）。6匹ごとに ♥ が1つ回復（満タンなら +200）
- **起こしてしまう**：空振りすると寝ている人が身じろぎする（HUDの STIR ゲージ）。ゲージが満タン＝**5〜6回続けて空振り**すると、起きてしまってその夜は失敗（`AWAKE`）

## 遊びの芯

**「予備動作を読む」ことがそのまま攻略になる**ようにした。

- 蚊は飛んでいる間ずっと手から逃げる（近づけると加速する）。だから「とりあえず連打」は通用しない
- 着地の0.3秒前から羽音の音程が上がり、ホバリングで止まる。**音と見た目の両方**が予告になる
- 叩けるのは `hover` / `land` / 飛行中すべて。ただし**当たり半径が違う**（着地18px・ホバー15px・空中10px）。
  空中は手が近づくと身をかわすので、先読みして叩くと +130。
- 外すと0.3秒の硬直（＝手の戻り）が残り、**26px以内にいた蚊は驚いて飛び去る**（＝連打が通用しない）
- 2晩目からは**2匹同時**。1匹ずつ確実に仕留めないと、待っている間にもう1匹が寄ってくる

暗闇で見えないこと自体をゲームにしているので、代わりの手がかりを多重化した：
月明かりの帯（見える）／羽音の距離と音程（聞こえる）／空気の波紋（うっすら見える）／肌の赤い腫れ（刺される前に見える）。

奥へ進むほど蚊が速く（1.0 → 1.55倍）、**猶予が短く**（1.0 → 0.56倍）、**顔（肌）を狙う確率**が上がる。

どの部屋も「色を変えただけ」ではなく、**窓の位置・床・家具・小物**をそれぞれ作り直している
（`scene.js` の `drawTokonoma` / `drawChabudai` / `drawBedFrame` / `drawDesk` / `drawPoster` / `drawSudare` / `drawChime` / `drawCoil` / `drawCityWindow` / `drawFireplace` / `drawSnowWindow` / `drawTrainWindow` / `drawSeaWindow` / `drawTentWall` / `drawMosquitoNet`）。
新しい部屋は `shellPal()`（壁・腰板・床・枠）と `beddingTone()`（シーツ・枕・布団）で色を組み立てるので、
1部屋あたり20行ほどで「別の部屋」を足せる。

寝ている人も部屋ごとに変わる（`heads.js`）。同じ仰向けの姿勢のまま、髪型・ひげ・帽子・髪色だけを差し替える:
`short` / `kid`（寝癖）/ `long`（枕に流れる長髪）/ `beard` / `cap`（ニット帽）/ `grey`（白髪）。

奥へ進むほど蚊が速く、**顔（肌）を狙う確率**が上がる。クリアすると ♥ が1つ回復。
3晩を越えると `ALL CLEAR`。

## 手

上から見た**右手の甲**を24×30のドットで描き、指4本・親指・先細りの手首で「手」と読ませる。
指に沿って1pxの明暗の縞を引くと「ソーセージの束」に見えるので、陰影は**指先・指の付け根のこぶ・
甲の稜線だけ**。こぶを全幅の帯にすると腕輪に見えるため、指の付け根ごとに4つに分けている。
照準は手のひら中心の1pxの点のみ。叩いた瞬間は指を4px縮めた別スプライトに差し替えて「つぶれ」を作る。
手の影は半透明ディザだと「水たまり」に見えるので、ベタの中間色で落とす。

## 寝姿

**仰向けで天井を向いて眠っている人**を、斜め上から見た絵（36×26）。
顔は上を向いているので、上から見おろした形に**縦をつぶして**描く（額は広く、あごは短い）。
閉じた目・眉・鼻・口を置き、髪は枕の上に散らす。横向きの体に正面の顔を付けると気持ち悪くなるため、
顔のパーツは全部「上から見た顔」の配置にしてある。
顔は布団より**手前**に描く（布団の縁が頭の後ろに回る）ので、顎まで見える。
呼吸で頭が1px上下し、掛け布団の胸のあたりが同じ周期で持ち上がる（＝予備動作とは別の「二次動作」）。
刺されると頬に赤い腫れが3点出る。寝息（Zzz）は頭の右上へ流れる。

表情は `drawSleeperHead(..., expr)` で切り替える。

| expr | いつ | 見た目 |
|---|---|---|
| `sleep` | プレイ中 | 閉じた目、Zzz |
| `happy` | 夜を越えた | 目が ^ ^ 、口が笑う、頬に赤み |
| `ouch` | 刺されきった | 眉を寄せ、口を開け、汗 |
布団は顎のすぐ下まで掛かっているので、首が浮いて見えない。

コンボと失敗の演出:

- **コンボ特典**（3匹ごと）… 画面の縁が暖色で脈打ち、頭のまわりに輪が広がり、`COMBO x3 / BONUS +210` が浮かび上がる。
  音は上がっていく3音。6匹ごとに ♥ 回復（`+1 SLEEP`）。
- **起こしてしまう**（空振りが重なったとき）… 空振りのたびに頭がびくつき、HUDの **STIR ゲージ**が伸びる
  （`DON'T WAKE THEM`）。満タンで**目を見開いた顔**（`expr="awake"`）＋赤い警告＋`WAKE UP!`＋`!` の点滅、
  リザルトは `AWAKE` / `WOKE THEM UP`。

HUDで「分かりにくい」を潰したところ:

- **羽音スコープ**（右下）… 部屋を上から見た小さな枠に、自分の頭と蚊の位置を点で出す。近いほど暖色、着地中は赤く脈打つ
- **ホバーの窓**（蚊のまわり）… 予備動作の0.32秒を、縮んでいく輪で表示。輪が体に重なる直前が「いま叩ける」
- **捕獲ピップ**（右上）… `SWAT 3/5` の文字ではなく、5つの四角が埋まる
- **コンボと硬直**（左上／手の下）… 連続数と、打てない間の細いバー（連打が効かない理由が見える）
- **`1 BITE LEFT`**（♥1のとき）… 残り1回で負けることを点滅で警告

## 終わりの演出

夜を越えたときと刺されきったときは、結果パネルの前に**1.9秒の間**を置いて顔が演技する（`game.js drawCutscene`）。

- **クリア（NIGHT CLEAR / ALL CLEAR）**：画面全体を夜明けの暖色に寄せ、頭のまわりを光の粒が12個舞い上がる。
  顔は ^ ^ の笑顔。バナーは顔を隠さないよう画面上部の帯に出す。
- **失敗（ITCHY!）**：頭が左右に揺れ、頬と首に湿疹が**時間とともに増えて大きくなる**。
  頬を3本の引っかき傷が滑り、文字は小刻みに震える。結果パネルは「NO SLEEP」。

### 速度

1フレームの内訳（Node、320×180）は **update 0.004ms / draw 1.0ms / composite 0.4ms**。
以前は draw が **55ms**（実測18fps）で、原因は掛け布団を600頂点の `poly()` で塗っていたこと。
`poly()` は「バウンディングボックス × 頂点数」の総当たりなので 1フレーム 1200万回の内外判定になっていた。
列ごとの高さで決まる形なので、列ごとの `rect()` に置き換えて同じ絵のまま **約50倍**にした。

### pixelfx との関係

描画はすべて pixelfx の **フレーム（color + light の2バッファ）** に対して行い、
最後に `composite()` で RGBA にする。おかげでブラウザなしでも同じ絵をPNGに焼ける。

```bash
cd vendor/pixelfx && node tools/render.mjs impacts/hit-spark   # 平手の火花を単体で確認
```

pixelfx のエフェクトは空振りの土煙（`thud`）にだけ使い、**当たりの飛沫は自前**（`game.js addSpark`）にした。
ライブラリの `hit-spark` / `crit-hit` は金色の星が大きく光り、この静かな寝室の絵から浮いていたため。

> ⚠️ `fx.draw()` は描画原点を `place()` したまま返すことがある。呼んだ直後に `p.reset()` しないと、
> **その後に描く掛け布団が画面外にずれて「叩くと布団が消える」**（実際にそうなっていた）。

## うまく遊べないとき

- **画面に「KA」は出るのに、タップしても何も起きない**
  以前はこれが起きました。サーバが `/` に `game/index.html` の中身をそのまま返していたため、
  HTML 内の `./src/main.js` が `/src/main.js` に解決されて 404 になり、JavaScript が一切動いていませんでした。
  いまは `/` → `/game/` に **302 リダイレクト**し、スクリプトは絶対パス（`/game/src/main.js`）で読み込みます。
  同じ事故を防ぐために `npm run smoke` を追加しました（リダイレクト・HTML内の参照・import 先 28 本をHTTPで確認）。

- **読み込みに失敗した**
  画面下に赤い帯でエラー文が出ます（`index.html` の番犬が `main.js` の起動を確認している）。
  キャッシュが疑わしいときはスーパーリロード。

- **音が出ない**
  最初のタップで AudioContext が有効になります。`M` で無音の切り替え。音がなくても遊べます。

- **叩いた瞬間の1〜2フレームだけ、布団が消える／絵がずれる**
  pixelfx のエフェクトが描画原点を戻さずに終わるのが原因でした。`game.js` でエフェクトを描いた直後に
