# KA — 夜の蚊取り

> 蚊 × 睡眠。3晩（和室 → 洋室 → 夏の夜）、1晩40〜45秒。
> **着地の直前に「止まる」一瞬**が最大の狙い目。**飛んでいる蚊も、小さい判定で叩ける。**

暗い寝室。耳元で羽音がする。蚊は壁・布団・そしてあなたの顔に着地する。
着地の0.3秒前、蚊はホバリングして震える（＝予備動作）。そこが唯一の狙い目。
飛んでいる最中に叩ければ大きな加点（+130）、遅れれば刺される。空振りすると近くの蚊は驚いて逃げる。

```
npm run dev          # http://localhost:5173/game/  (320x180 を整数倍で拡大)
```

- **操作**：マウス／指で手を動かす、タップ／Space で平手。`M` 無音、`P` 原則ラベルの表示切替、`R` タイトルへ
- **ルール**：各晩の蚊を全部捕まえれば夜明け前でもクリア、次の部屋へ（クリアで ♥ が1つ回復）。刺されると睡眠（♥3）が減り、0でその夜は終わり
- **得点**：捕獲 +100 / **空中で捕獲 +130** / 着地から素早く叩く +50 / 連続ボーナス、ステージクリア +500＋残り時間×10、夜明け +100

## 12のアニメーション原則 → 実装

| # | 原則 | この作品での実装 | コード |
| --- | --- | --- | --- |
| 1 | つぶれ・伸び | 手のひらが振りかぶりで縦に伸び、当たった瞬間に横に潰れる（sx 1.36 / sy 0.62）。当たった蚊は潰れて壁のシミになる | `hand.js slapPose`, `game.js drawSplat` |
| 2 | 予備動作 | 蚊が着地の0.32秒前にホバリングして震える。手も打つ前に0.08秒引く（進行度 -0.3） | `mosquito.js state:"hover"`, `hand.js strikeProgress` |

## 遊びの芯

**「予備動作を読む」ことがそのまま攻略になる**ようにした。

- 蚊は飛んでいる間ずっと手から逃げる（近づけると加速する）。だから「とりあえず連打」は通用しない
- 着地の0.3秒前から羽音の音程が上がり、ホバリングで止まる。**音と見た目の両方**が予告になる
- 叩けるのは `hover` / `land` / 飛行中すべて。ただし**当たり半径が違う**（着地18px・ホバー15px・空中10px）。
  空中は手が近づくと身をかわすので、先読みして叩くと +130。
- 外すと0.3秒の硬直（＝手の戻り）が残り、**26px以内にいた蚊は驚いて飛び去る**（＝連打が通用しない）
- 2晩目からは**2匹同時**。1匹ずつ確実に仕留めないと、待っている間にもう1匹が寄ってくる

暗闇で見えないこと自体をゲームにしているので、代わりの手がかりを多重化した：
月明かりの帯（見える）／羽音の距離と音程（聞こえる）／空気の波紋（うっすら見える）／肌の赤い腫れ（刺される前に見える）。

奥へ進むほど蚊が速く、**顔（肌）を狙う確率**が上がる。クリアすると ♥ が1つ回復。
3晩を越えると `ALL CLEAR`。

## 手

上から見た**右手の甲**を24×30のドットで描き、指4本・親指・袖口で「手」と読ませる。
前の版は指に沿って1pxの明暗の縞を引いていたため、指がソーセージの束に見えていた。
いまは**陰影は指先と甲の稜線だけ**に絞り、指の区切りは輪郭の暗線に任せている。
照準は手のひら中心の1pxの点のみ（十字は指の上で青いゴミに見えたので廃止）。
叩いた瞬間は指を4px縮めた別スプライトに差し替えて「つぶれ」を作る。

## 寝姿

真横からの眺めで、**壁の方を向いて寝ている**（＝カメラには後頭部と耳だけが見える）。
正面や横顔を描くと「起きているのに寝ている」ように見えて不気味だったので、
顔のパーツは出さず、**後頭部の丸み・耳・月明かりのリム・3本の毛束**だけで「横向きに寝ている人」を読ませている。
呼吸で頭が1px上下し、掛け布団の胸のあたりが同じ周期で持ち上がる（＝予備動作とは別の「二次動作」）。
刺されると耳のふちが3px赤く腫れる。
布団は顎のすぐ下まで掛かっているので、首が浮いて見えない。

## 構成

```
game/
  index.html          画面とタイトル（日本語はHTML側、ゲーム内はピクセルフォント）
  src/
    palette.js        色（月光の青／肌の暖色の2系統だけ）
    scene.js          寝室の静的背景・寝顔・ホコリ・月明かりの帯
    mosquito.js       蚊の状態機械（fly→approach→hover→land→escape）
    head-rows.js      横向き（後頭部）の頭のドット絵 36×31
    hand.js           手のキーフレームと弧・つぶれ（24×30 を文字スプライトで設計）
    fx.js             pixelfx の impact エフェクト接続
    audio.js          WebAudio の羽音・平手・刺し跡（外部ファイルなし）
    game.js           進行・判定・HUD・リザルト
    main.js           入力・音・ループ（320x180 → 整数倍拡大）
  tools/
    preview.mjs       Node でフレームをPNGに（ブラウザ不要のQA）
    sim-test.mjs      ロジックの回帰テスト
    dom-test.mjs      最小DOMスタブで main.js を走らせる回帰テスト
```

### pixelfx との関係

描画はすべて pixelfx の **フレーム（color + light の2バッファ）** に対して行い、
最後に `composite()` で RGBA にする。おかげでブラウザなしでも同じ絵をPNGに焼ける。

```bash
cd vendor/pixelfx && node tools/render.mjs impacts/hit-spark   # 平手の火花を単体で確認
```

pixelfx のエフェクトは空振りの土煙（`thud`）にだけ使い、**当たりの飛沫は自前**（`game.js addSpark`）にした。
ライブラリの `hit-spark` / `crit-hit` は金色の星が大きく光り、この静かな寝室の絵から浮いていたため。

> ⚠️ `fx.draw()` は描画原点を `place()` したまま返すことがある。呼んだ直後に `p.reset()` しないと、
> **その後に描く掛け布団が画面外にずれて「叩くと布団が消える」**（実際にそうなっていた）。

## うまく遊べないとき

- **画面に「KA」は出るのに、タップしても何も起きない**
  以前はこれが起きました。サーバが `/` に `game/index.html` の中身をそのまま返していたため、
  HTML 内の `./src/main.js` が `/src/main.js` に解決されて 404 になり、JavaScript が一切動いていませんでした。
  いまは `/` → `/game/` に **302 リダイレクト**し、スクリプトは絶対パス（`/game/src/main.js`）で読み込みます。
  同じ事故を防ぐために `npm run smoke` を追加しました（リダイレクト・HTML内の参照・import 先 28 本をHTTPで確認）。

- **読み込みに失敗した**
  画面下に赤い帯でエラー文が出ます（`index.html` の番犬が `main.js` の起動を確認している）。
  キャッシュが疑わしいときはスーパーリロード。

- **音が出ない**
  最初のタップで AudioContext が有効になります。`M` で無音の切り替え。音がなくても遊べます。

- **叩いた瞬間の1〜2フレームだけ、布団が消える／絵がずれる**
  pixelfx のエフェクトが描画原点を戻さずに終わるのが原因でした。`game.js` でエフェクトを描いた直後に
  `p.reset()` を呼んで解決済み。同じ症状が出たら、新しく足した描画の前後で `place()` が残っていないかを見る。

- **蚊が見つからない**
  月明かりの帯（窓からの光）を通るとき、または着地したときに見えます。
  羽音が近いほど高く大きくなり、空気の波紋でも位置がわかります。
